# 3D Viewer

以 Python 製作的 3D CAD 檢視/建模工具(CadQuery + PyVista + PyQt5),繁體中文介面。

## 安裝與執行(Windows 11)

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py [專案.v3d 或 檔案.step]
```

## 測試

```
pip install pytest
python -m pytest tests
```

## 使用重點

- 所有建模操作都記錄在「特徵歷史」;雙擊特徵可改參數,後續特徵自動重算。
- 專案存成 `.v3d`(JSON,匯入的 STEP 內嵌於檔內);另可匯入/匯出 STEP/STP。
- `Ctrl+Z` / `Ctrl+Y` 復原與重做;重算失敗的特徵會標示 ⚠ 並略過。

## 鎖定平面與參考面

- 選取模式:面 → 點一個平面 → `F3` 鎖定;鎖定後建立的實體/草圖/螺紋孔都放在該平面上(`F3` 再按解除)。
- 「平面」選單可鎖定 XY/XZ/YZ,或以鎖定平面建立**參考面**(沿法向偏移、可繞 X/Y 軸傾斜)。
- 參考面也能當基準再建參考面;在「參考面」清單選取後按 `F3` 鎖定,或用「移動/編輯所選參考面」改偏移。
- 建立在參考面上的特徵會跟著參考面移動(重算);刪除參考面後則使用建立當時的位置。

## 草圖

1. 鎖定平面(`F3` 或「平面」選單)→ 「草圖 → 在鎖定平面上新建草圖」(`F4`),畫面會正視於該平面並出現草圖工具列。
2. 工具:選取、線(連續)、矩形、圓、圓弧(三點)、修整、刪除、鏡射、陣列(線性/圓形)。
   - 滑鼠點選時會吸附到端點/圓心/中點與格點(可關閉);右鍵或 `Esc` 結束連續線。
   - 工具列的輸入欄可輸入數值:`x,y` 絕對座標、`@dx,dy` 相對、`@長度<角度` 極座標、單一數字(圓為半徑,線為長度)。
   - 修整:點選線段,會在與其他圖元的交點之間切開並刪除所點的那一段。
   - 鏡射/陣列作用於已選取的圖元(未選取則全部)。
3. 「✔ 完成草圖」後,用「草圖 → 草圖拉伸/旋轉」產生新實體、聯集或切除;雙擊「草圖」清單可再編輯,相關特徵會自動重算。
- 封閉輪廓需首尾相接(或使用圓);輪廓內再包含的封閉輪廓視為孔洞。

### 拘束與尺寸標註

草圖模式第二列工具列提供拘束與尺寸,右側「拘束與尺寸」清單可檢視、編輯、刪除;工具列右側顯示**自由度**(0 = 完全定義)。

- 自動拘束:新畫圖元的端點/圓心落在既有圖元的特徵點上,會自動加「重合」;矩形另加水平/垂直。
- 幾何拘束:重合、水平、垂直、平行、垂直相交、相切(線-圓、圓-圓)、等長/等半徑、同心、固定、中點、點在物體上。
- 尺寸(驅動尺寸):長度/直徑/半徑(點選線或圓)、兩點距離、水平距離、垂直距離、兩線角度。輸入數值後幾何立即重算;雙擊清單中的尺寸可改值。
- 與既有拘束衝突或無法求解時,新拘束/新數值會被拒絕並還原。
- 拘束存在草圖特徵內(`.v3d`),再次編輯草圖時仍有效。
- 求解器為內建的 Levenberg-Marquardt(純 numpy),不需額外套件。

## 另存新檔 / 匯出

- 「檔案 → 另存新檔」可選存成專案(`.v3d`)、STEP 或 STL;也可用「匯出 STEP / 匯出 STL」。
- STL 匯出會詢問精細度:標準(弦高誤差 0.05 mm)、**高(預設,0.01 mm)**、超高(0.002 mm);預設為二進位,可選 ASCII。

## 草圖掃掠

- 準備兩個草圖:**輪廓**(封閉輪廓,可含孔洞)與**路徑**(相連的線/圓弧,不可分岔)。
- 「草圖 → 草圖掃掠」選好輪廓、路徑與操作(新實體/聯集/切除)。輪廓需位於路徑起點並垂直於路徑起始方向;
  若位置不對,勾選「自動對齊」會把輪廓座標系移到路徑起點(保留輪廓在草圖內的相對位置)。
- 「輪廓隨路徑轉向」建議保持勾選;轉角處理可選 transformed / round / right。

### 螺旋線路徑

- 鎖定平面後,「草圖 → 在鎖定平面建立螺旋線路徑」:軸線為平面法向,起點在平面原點 + 半徑 × 平面 X 軸;可設螺距、高度、起點半徑、錐角(0 = 圓柱)與左旋。
- 螺旋線可在草圖掃掠中當路徑,做彈簧、螺紋、盤管:輪廓草圖畫在含螺旋軸的平面上並圓心置於起點,或勾選「自動對齊」(輪廓座標系的 X = 徑向、Y = 軸向,原點在螺旋起點)。
- 螺旋線的參數(螺距、高度、半徑…)可隨時改,掃掠結果自動重算。

## 視角方塊與 HOME

- 右上角的六面體取代原本的 XYZ 座標軸,方向永遠與目前視角一致。
- 點選方塊的**面**切換為前/後/左/右/上/下視圖;點**邊**或**角**切換為兩軸/三軸的斜向視角(例如點前上右的角 = 等角視)。
- 方塊下方的 **HOME** 按鈕回到初始視角(等角視並顯示全部)。

## 顯示精細度

- 「檢視 → 顯示精細度」可選低 / 標準 / **高(預設)** / 超高,調整圓、圓柱等曲面與曲線邊、草圖圓的平滑程度;只影響畫面,不影響模型、STEP 與 STL 匯出。
- 設定會記住,下次開啟沿用。模型很大或很複雜時若覺得卡頓,可調低。

## 量測工具

「量測」選單選一個工具後,直接在 3D 視窗點選;靠近頂點會自動吸附,結果顯示在右側「量測結果」並在畫面標註(黃色),可複製或清除。

- **點到點距離**:兩點的距離與 ΔX/ΔY/ΔZ、座標。
- **圖元間最短距離**:頂點/邊/面任意兩者之間的最短距離與最近點(平行面即為面間距)。
- **邊長 / 半徑**:邊的長度;圓與圓弧另顯示半徑、直徑、圓心。
- **面積 / 面資訊**:面積、種類;平面顯示法向,圓柱/球顯示半徑。
- **角度**:平面-平面(內夾角)、直線-直線、直線-平面。
- **所選實體的屬性**:體積、表面積、質心、外型尺寸與邊界框。
- 模型有任何修改後,畫面上的量測標註會自動清除(文字紀錄保留)。
- 數值**最多顯示 3 位小數(.3f)並去掉多餘的 0**:整數維持整數(`50 mm`),`0.1` 顯示 `0.1`,`0.25` 顯示 `0.25`,`0.1234` 顯示 `0.123`。「量測 → 量測小數位數」可改為 0~8 位(會記住);同一設定也用於半徑/直徑標註、草圖尺寸標註與實體屬性。工程圖上的尺寸也採相同精簡寫法。

## 半徑 / 直徑標註

- 「標註」選單的「半徑標註」「直徑標註」:點選圓/圓弧邊、圓柱面或球面,在 3D 視窗建立引線、箭頭與數值(R6、Ø12)。
- 標註是模型特徵:存在特徵歷史與 `.v3d` 專案內,模型尺寸改變(例如孔徑)時數值自動更新;不適用(圓不存在或不是圓)時會標示 ⚠。
- 左側「標註」清單雙擊可在半徑/直徑間切換,「標註 → 刪除所選標註」可移除。
- 與一次性的「量測」不同,標註不會在模型修改後被清除。

## 特徵歷史進階操作

- 在「特徵歷史」按右鍵(或「編輯」選單):編輯參數、重新命名、**抑制 / 取消抑制**、**回溯**、上移 / 下移、刪除。
- 抑制:該特徵在重算時略過(灰色斜體),依賴它的特徵會標示 ⚠。
- 回溯:「回溯到此特徵之後」只計算到該特徵,之後的特徵灰顯;此時新增的特徵會插在回溯點之後。「回到最新」解除回溯。
- 自訂名稱、抑制狀態與回溯點都會存進 `.v3d`。

## 3D 陣列 / 鏡射 / 孔 / 抽殼

- **3D 陣列**(變換選單):先在「實體」清單選實體,選線性(數量、各軸間距)或圓形(數量、總角度、旋轉軸:X/Y/Z 或鎖定平面法向);各份聯集成同一實體。想做「陣列孔」可先建一個圓柱當刀具,陣列後再布林差集。
- **鏡射實體**:對 XY / XZ / YZ 或鎖定平面鏡射,可聯集回原實體或另建新實體。
- **孔**(建立選單):鎖定平面後,輸入孔位置(`u,v; u,v`,平面座標)、孔徑、孔深(0 = 通孔),支援簡單孔、沉頭孔、埋頭孔,預設往實體內鑽,可反向。
- **抽殼**(修飾選單):選取模式:面 選要開口的面,輸入壁厚與方向(向內/向外);未選面則做封閉空心。壁厚過大導致結果無效時會報錯。

## 截面視圖與外觀

- **截面視圖**(檢視選單):選 XY / XZ / YZ 或鎖定平面,輸入沿法向的位置,切掉法向正側以看內部(截開的內側以深色顯示,並畫出半透明截面平面);「反向」保留另一側,「關閉截面」取消。截面只影響畫面。
- **外觀**:在「實體」清單按右鍵可設定**顏色**、**透明度**、**隱藏/顯示**、重設;「檢視 → 全部顯示」取消所有隱藏。外觀記錄為特徵(可復原、存進專案),隱藏的實體不會被點選到。

## 草圖放樣

- 準備 2 到 4 個封閉輪廓草圖(位於不同位置的平面),「草圖 → 草圖放樣」依序選輪廓,可選平滑或直紋(各段直線連接),操作可為新實體/聯集/切除。輪廓內若有多個封閉輪廓,取面積最大的外輪廓。

## 變數與公式

- 「編輯 → 變數與公式」:每行 `名稱 = 數字或算式`,後面的可引用前面的,算式可用 `+ - * / ** %`、括號、`pi`、`sqrt`、`sin`/`cos`(弧度)、`min`/`max`/`abs`/`round` 等。
- 所有特徵對話框的數值欄位都可輸入數字,或以 `=` 開頭的算式(例如 `=孔徑/2`、`=寬+2*壁厚`)。改變數後所有相關特徵自動重算;變數存進 `.v3d`,算式無效或未定義會標示 ⚠ 並拒絕。
- 目前公式適用於特徵參數,草圖尺寸(拘束)與座標仍為數字。

## 工程圖輸出

- 「檔案 → 輸出工程圖」:選紙張(A4/A3/A2 橫式)、投影法(第三角/第一角)、比例(自動挑不超出圖面的最大標準比例,或手動指定)與視圖(前、上、右、等角)。
- 圖面含:隱藏線消除的投影(可選顯示隱藏線虛線)、各視圖總尺寸標註、圓孔的中心線與 Ø 直徑標註、圖框與標題欄(圖名、零件名稱、比例、單位、設計者、日期、投影法/紙張)。
- 先顯示預覽,再「儲存為 PDF / SVG / PNG / DXF」;DXF 依線型分圖層(OUTLINE、HIDDEN、DIM、CENTER、FRAME、TEXT)。
- 隱藏(外觀)的實體不會畫入工程圖。

### 工程圖:剖視圖與更多尺寸標註

- **剖視圖**:工程圖設定選「前剖(XZ 平面)/側剖(YZ 平面)/上剖(XY 平面)」,剖切位置為零件中心加上偏移量。剖視圖畫在右上位置(與等角視共用,剖視優先),切到的面以 45° 剖面線填滿(孔、空腔內不畫),並在對應視圖畫出剖切線、視線箭頭與代號 A-A;DXF 另有 HATCH 圖層。
- **更多尺寸**:孔位置座標尺寸(自視圖左下角量起,標在視圖上方與左方)、圓角半徑 R(含引線)、同心圓的多個 Ø 直徑(引線錯開),以及可選的**分段(鏈式)尺寸**(依可見直線邊的位置分段)。尺寸數值取自精確的 3D 外框,不受曲線取樣影響。

## 質量屬性(含材料)與干涉檢查

- **材料**:在「實體」清單按右鍵 → 材料,從內建材料庫(碳鋼、不鏽鋼、鋁、銅、黃銅、鈦、ABS、PLA、尼龍、PC…共 24 種)選擇,或自訂密度(g/cm³)。材料記錄為特徵(可復原、存進專案),清單會顯示 `[材料]`。
- **質量屬性**(量測選單):整體質量、體積、質心、對質心的慣性矩(Ixx/Iyy/Izz 與乘積慣性、主慣性矩),並列出各實體的密度、體積、質量;未指定材料的實體以你選的預設材料計算;可在畫面標出質心(CoM)。多個實體以平行軸定理合成。單位:mm、g、g·mm²。
- **干涉檢查**(量測選單):對所有實體兩兩檢查,列出重疊體積與位置,可同時列出僅接觸(貼合)的實體;干涉區域以紅色顯示,實體暫時半透明以便看到內部。

## 拔模與加肋
- 修飾 → 拔模(所選面):指定角度、中立平面(XY/XZ/YZ 或鎖定平面)與偏移,可反向。
- 草圖 → 加肋:以開放輪廓草圖產生肋板,指定厚度、對稱、反向,自動與所選實體融合。

## 2D 草圖補強
- 新增工具:橢圓、雲形線(右鍵/Esc 完成)、2D 圓角、2D 倒角、偏移曲線。
- 構造線切換(不參與輪廓/實體生成)與「投影模型邊」到草圖。

## 便利功能
- 檔案 → 最近開啟的檔案:保留最近 10 個專案,不存在的檔案自動移除。
- 自動儲存:每 60 秒將未儲存的變更備份;正常儲存/關閉會清除備份,當機後下次啟動會詢問是否恢復。
- 量測 → 顯示單位(mm / cm / m / in):只影響量測與屬性文字的顯示,建模輸入仍為 mm。

## 組合件
- 組合件 → 插入零件:把另一個 .v3d 專案的實體插入為新實體(可指定位置);STEP 走一般匯入。
- 配合(面貼合 / 同軸):先在要移動的零件上選一個面並執行「步驟 1」,再於固定零件選一個面並執行「步驟 2」。
  面貼合可設間距與同向;同軸對齊圓柱/圓錐軸線。已滿足的自由度不會被改動,可連續配合(如先同軸再面貼合)。
- 配合是特徵歷史的一部分,可編輯、抑制、復原。

## MCP 工具(用自然語言控制)
同一個 repo 內的 `mcp_server/` 提供 MCP 伺服器,讓 Claude 等 LLM 以工具呼叫建立/修改模型(建基本實體、草圖、拉伸/切除、圓角、布林、組合件、量測、匯出、截圖等)。

- 安裝:`pip install mcp`(已列入 requirements.txt)
- 兩種模式(自動選擇):
  - **即時**:在 3D Viewer 選單「說明 → 啟用 MCP 橋接」(僅本機 127.0.0.1 + 隨機 token,預設關閉),LLM 的操作會即時顯示在視窗,並可用 Ctrl+Z 復原。
  - **無頭**:視窗未開時直接在背景處理專案,用 `open_project` / `save_project` 讀寫 .v3d。
- Claude Code:`claude mcp add 3dviewer -- python -m mcp_server`(需在專案目錄,或用絕對路徑指定 cwd)
- Claude Desktop(`claude_desktop_config.json`):
  ```json
  {"mcpServers": {"3dviewer": {"command": "python", "args": ["-m", "mcp_server"], "cwd": "C:\\path\\to\\PeterHuang"}}}
  ```
- 範例:「建立 40×30×20 的方塊,把四條垂直邊倒圓角 3,再在頂面中央切一個直徑 10 的通孔,匯出 STL」。
- 邊/面以索引指定,LLM 會先呼叫 `find_faces` / `find_edges` 取得;錯誤會以中文回傳且模型自動還原,LLM 可自行修正重試。
