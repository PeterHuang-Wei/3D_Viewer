# 3D Viewer

以 Python 製作的 3D CAD 檢視/建模工具(CadQuery + PyVista + PyQt5),繁體中文介面。

## 安裝與執行(Windows 11)

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py [專案.v3d 或 檔案.step]
```

## 測試

```
pip install pytest
python -m pytest tests
```

## 使用重點

- 所有建模操作都記錄在「特徵歷史」;雙擊特徵可改參數,後續特徵自動重算。
- 專案存成 `.v3d`(JSON,匯入的 STEP 內嵌於檔內);另可匯入/匯出 STEP/STP。
- `Ctrl+Z` / `Ctrl+Y` 復原與重做;重算失敗的特徵會標示 ⚠ 並略過。

## 鎖定平面與參考面

- 選取模式:面 → 點一個平面 → `F3` 鎖定;鎖定後建立的實體/草圖/螺紋孔都放在該平面上(`F3` 再按解除)。
- 「平面」選單可鎖定 XY/XZ/YZ,或以鎖定平面建立**參考面**(沿法向偏移、可繞 X/Y 軸傾斜)。
- 參考面也能當基準再建參考面;在「參考面」清單選取後按 `F3` 鎖定,或用「移動/編輯所選參考面」改偏移。
- 建立在參考面上的特徵會跟著參考面移動(重算);刪除參考面後則使用建立當時的位置。

## 草圖

1. 鎖定平面(`F3` 或「平面」選單)→ 「草圖 → 在鎖定平面上新建草圖」(`F4`),畫面會正視於該平面並出現草圖工具列。
2. 工具:選取、線(連續)、矩形、圓、圓弧(三點)、修整、刪除、鏡射、陣列(線性/圓形)。
   - 滑鼠點選時會吸附到端點/圓心/中點與格點(可關閉);右鍵或 `Esc` 結束連續線。
   - 工具列的輸入欄可輸入數值:`x,y` 絕對座標、`@dx,dy` 相對、`@長度<角度` 極座標、單一數字(圓為半徑,線為長度)。
   - 修整:點選線段,會在與其他圖元的交點之間切開並刪除所點的那一段。
   - 鏡射/陣列作用於已選取的圖元(未選取則全部)。
3. 「✔ 完成草圖」後,用「草圖 → 草圖拉伸/旋轉」產生新實體、聯集或切除;雙擊「草圖」清單可再編輯,相關特徵會自動重算。
- 封閉輪廓需首尾相接(或使用圓);輪廓內再包含的封閉輪廓視為孔洞。

### 拘束與尺寸標註

草圖模式第二列工具列提供拘束與尺寸,右側「拘束與尺寸」清單可檢視、編輯、刪除;工具列右側顯示**自由度**(0 = 完全定義)。

- 自動拘束:新畫圖元的端點/圓心落在既有圖元的特徵點上,會自動加「重合」;矩形另加水平/垂直。
- 幾何拘束:重合、水平、垂直、平行、垂直相交、相切(線-圓、圓-圓)、等長/等半徑、同心、固定、中點、點在物體上。
- 尺寸(驅動尺寸):長度/直徑/半徑(點選線或圓)、兩點距離、水平距離、垂直距離、兩線角度。輸入數值後幾何立即重算;雙擊清單中的尺寸可改值。
- 與既有拘束衝突或無法求解時,新拘束/新數值會被拒絕並還原。
- 拘束存在草圖特徵內(`.v3d`),再次編輯草圖時仍有效。
- 求解器為內建的 Levenberg-Marquardt(純 numpy),不需額外套件。

## 另存新檔 / 匯出

- 「檔案 → 另存新檔」可選存成專案(`.v3d`)、STEP 或 STL;也可用「匯出 STEP / 匯出 STL」。
- STL 匯出會詢問精細度:標準(弦高誤差 0.05 mm)、**高(預設,0.01 mm)**、超高(0.002 mm);預設為二進位,可選 ASCII。
