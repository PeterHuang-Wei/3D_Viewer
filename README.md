# 3D Viewer

以 Python 製作的 3D CAD 檢視/建模工具(CadQuery + PyVista + PyQt5),繁體中文介面。

## 安裝與執行(Windows 11)

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py [專案.v3d 或 檔案.step]
```

## 進度

- [x] 第一階段:主視窗、3D 顯示、STEP/STP 讀寫、標準視角、線框/邊線
- [x] 第二階段:基本實體、草圖拉伸、平移旋轉、布林運算
- [x] 第三階段:面/邊選取、倒角、圓角
- [x] 第四階段:螺牙(外/內)
- [x] 第五階段:特徵樹、參數重算、復原/重做、專案檔

## 測試

```
pip install pytest
python -m pytest tests
```

## 使用重點

- 所有建模操作都記錄在「特徵歷史」;雙擊特徵可改參數,後續特徵自動重算。
- 專案存成 `.v3d`(JSON,匯入的 STEP 內嵌於檔內);另可匯入/匯出 STEP/STP。
- `Ctrl+Z` / `Ctrl+Y` 復原與重做;重算失敗的特徵會標示 ⚠ 並略過。

## 鎖定平面與參考面

- 選取模式:面 → 點一個平面 → `F3` 鎖定;鎖定後建立的實體/草圖/螺紋孔都放在該平面上(`F3` 再按解除)。
- 「平面」選單可鎖定 XY/XZ/YZ,或以鎖定平面建立**參考面**(沿法向偏移、可繞 X/Y 軸傾斜)。
- 參考面也能當基準再建參考面;在「參考面」清單選取後按 `F3` 鎖定,或用「移動/編輯所選參考面」改偏移。
- 建立在參考面上的特徵會跟著參考面移動(重算);刪除參考面後則使用建立當時的位置。
